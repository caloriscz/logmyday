# Notifications

LogMyDay keeps you on schedule with reminders that surface required tags and deliver gentle nudges when something slips. Whether you prefer checking the dashboard or receiving Android notifications, the system adapts to your routine.

## Daily reminders on the web

- The Home page always shows what is left for the selected day. Required tags are listed with buttons to fill them quickly.
- When you switch dates, the list updates instantly so you can backfill past days or plan ahead.
- Each reminder includes shortcuts to use a default value or open the full add-activity modal for more detail.

## Notifications on Android

- After you sign in, the mobile app quietly checks for required tags that are still empty and posts a notification if anything needs attention.
- Tapping the notification opens the exact tag ready to fill in. No digging around the app to find the right page.
- You can configure how often the app checks, set quiet hours, and limit how many reminders you want per day.

## Managing the rules

- Configure notification schedules from the web dashboard alongside your tag settings.
- Decide which tags are important enough to trigger mobile alerts, set cooldowns between reminders, and pause notifications entirely when you need a break.

## Tips

- Keep the Android app signed in if you rely on background reminders; they pause automatically when you log out.
- During testing, shorten the interval to a few minutes to see how the workflow feels, then extend it once you are confident.
