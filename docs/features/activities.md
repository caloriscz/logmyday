# Activities

Activities are the heart of LogMyDay. Capture a coffee break, record a workout, jot down a mood, or save a quick reminder from either the web dashboard or the Android app, then revisit everything on calendars and timelines.

## How you log

- **On the web**: The Home page highlights anything you still need to fill in. Use the "Add activity" button for detailed entries or the "Use default" shortcut when you already know the answer.
- **Add Activity modal**: Available throughout the site, this modal remembers the day you are working on and adapts its inputs to the tag you pick—numbers show numeric fields, text shows a text box, and so on.
- **Quick buttons on Android**: Create one-tap shortcuts for the things you repeat every day. Each tap logs the activity instantly and starts a short cooldown so you do not double-submit by accident.
- **Guided tools**: Breathing exercises, timers, and other tools offer a "Save to log" option so the results land in the right place without retyping.

## Reviewing what you logged

- Use the Activities page (web or mobile) to see a daily timeline with filters for tags, keywords, and date ranges.
- Switch to calendar views when you want the bigger picture—month grids show streaks, while the linear calendar helps you backfill busy weeks.

## Tips

- Set default values on required tags for routines like vitamins or hydration; the "Use default" button completes them in one click.
- Turn on **Add another** in the modal when you are logging a batch of similar entries.
- Heading on a trip? Update your time zone in profile settings so new entries match the local clock.
