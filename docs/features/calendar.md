# Calendar

Calendar suite helps review history day by day, see the values together. You can switch between rich grid layouts and linear lists depending on how deeply you need to analyse the data.

## Views

- **Daily timeline**: See a running list of everything logged that day, complete with filters for tags, keywords, and time ranges.
- **Month grid**: The traditional calendar view highlights which days include entries and which are missing, making streaks easy to spot.
- **Linear calendar**: Prefer a scrolling journal? The linear view groups entries by week so you can skim at speed and backfill missed moments.

## Navigation helpers

- Jump by day, week, or month using navigation arrows or keyboard shortcuts.
- Quickly switch to another date with the culture-aware date picker; the entire dashboard follows your selection.
- Reminders board inherits the same navigation, letting you tackle required items for any day without leaving the page.

## On mobile

- Activities page mirrors filters and pagination while staying touch-friendly.
- Pull to refresh after busy periods or long flights to sync new entries.
- When you select a date, the add-activity modal launches with that day preselected—perfect for logging yesterday’s wins.
