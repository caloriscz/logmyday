# Tools

Tools extend LogMyDay beyond simple data entry. They guide you through breathing exercises, interval workouts, and other routines, then save the outcome straight into your activity log with a single tap.

## Available tools

- **Guided breathing**: Choose your inhale, hold, and exhale timings, follow the calming visualisation, and save the completed session to your log.
- **HIIT trainer**: Configure work and rest intervals, select the number of rounds, and capture your effort level once the workout finishes.
- **Exercise log**: Track sets, reps, intensity, or distance right from the web or mobile app without building custom forms.

## Works everywhere

- The web dashboard offers rich layouts with timers, progress visualisations, and quick links back to your activity history.
- The Android app mirrors the same tools with touch-friendly controls, offline support for timers, and a one-tap "Save to log" button when you are done.

## Logging the results

- Each tool suggests the tag you typically use, but you can switch to any tag before saving.
- Entries saved from tools behave like any other activity—they show up on calendars, trigger reminders, and appear in exports.
