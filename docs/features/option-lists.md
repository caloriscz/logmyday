# Option Lists

Option lists let you reuse curated sets of values—perfect for intensity levels, locations, meal types, or any label that should come from a drop-down instead of free text.

## Why option lists matter

- Ensure consistent wording for recurring choices, making charts and exports easier to read.
- Offer friendly display names while storing the underlying value you prefer (e.g., show "Great" but store "5").
- Share lists with your whole household or team so everyone speaks the same language.

## Managing lists

- Visit the Option Lists page on the web to create personal or shared lists.
- Add, reorder, or remove individual options with a simple modal editor.
- Mark a default option if most entries use the same choice; it saves time when logging from mobile quick buttons.

## Linking to tags

- When editing a tag, pick the option list you want it to use. The tag’s input automatically switches to a drop-down on both web and mobile.
- Pair option lists with required tags to guide consistent daily logging and avoid typos.
- Combine option lists with default values so quick-add buttons can submit a pre-selected choice without opening the full form.
