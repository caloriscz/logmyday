# Tags and Units

Tags define the structure of every activity you log. Combine different input types, default values, option lists, and measurement units to describe exactly what you want to track without asking developers for custom fields.

## What makes tags powerful

- **Flexible inputs**: Choose whether a tag should collect a number, free text, a yes/no answer, a date, a time, or even a start/end range. LogMyDay automatically shows the right control on web and mobile.
- **Units and quantities**: Attach units such as minutes, kilometres, cups, or repetitions so your reports stay meaningful and consistent.
- **Repeat rules**: Decide how often an activity can be recorded. Allow multiple logs per day for water intake or restrict to once per week for bigger milestones.
- **Required tracking**: Mark a tag as required when you never want to miss it. Required tags appear on the reminders board and can trigger notifications.

## Creating and editing tags

- Use the web dashboard to add new tags, choose their input type, assign a unit or option list, and set default values.
- Group tags into categories, toggle whether they show on the Home page, and define whether they are personal or shared across the team.
- Update or retire tags at any time—existing activities keep the data you already captured.

## Units or option lists?

- Choose a **unit** when you want a numeric value tied to a measurement (e.g., 30 minutes, 5 kilometres, 2 cups).
- Choose an **option list** when you want a drop-down of friendly labels (e.g., energy level: low/medium/high). See [Option Lists](option-lists.md) for more ideas.
