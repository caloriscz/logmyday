# Setup and Installation

This section walks through preparing a development workstation, restoring dependencies, and running LogMyDay locally or inside containers. LogMyDay pairs a Blazor Server dashboard with a MAUI mobile companion so you can log daily activities, add rich tag metadata, and review trends.

LogMyDay supports **SQLite** (recommended for getting started — no database server required) and **SQL Server** (recommended for multi-user production deployments). Start with **Local Development** to get the solution running on your machine, then review the Docker notes if you intend to host the app in containers.
