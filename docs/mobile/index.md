# Mobile Guide

LogMyDay ships with a MAUI Blazor Hybrid application (`LogMyDay.App.Mobile`) that gives you a touch-friendly interface, system notifications, and quick actions for logging activities. The pages in this section explain how to build the app, connect it to a server, and operate the most important workflows on Android.
