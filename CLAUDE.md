Production application repository for LogMyDay.

Read `../CLAUDE.md` first for workspace-wide agent instructions, hard rules, Taskino MCP workflow,
security constraints, and build/run governance.

Do not modify production code unless an existing Taskino task in the `LogMyDay` project authorizes
